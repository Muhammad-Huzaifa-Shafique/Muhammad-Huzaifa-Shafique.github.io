Casefile: a local assistant for penetration-testing notes

Casefile answers penetration-testing questions from public documentation (the HackTricks wiki and tool manual pages) and shows which passages each answer came from. Everything runs on my own computer: Ollama serves Llama 3.1 8B, and the vectors live in a Chroma database.

What I built. The whole pipeline: collect, chunk, embed, search, answer and check. I indexed the same 22,720 chunks with three embedding setups and ran seven test questions through all of them. I also wrote a citation checker, with 58 unit tests, that confirms every [n] citation points at a passage that was actually retrieved.

What I found. The embedding setup changes what the answer model gets to read. The three setups never agreed on all five top chunks, and on four of the seven questions they shared at most one. One question was deliberately off-topic (baking sourdough bread), and every setup gave it the lowest top-1 similarity of the seven.

Relevant to: retrieval-augmented generation, embeddings, vector search, local LLMs, evaluation.

  • Source code
Limit. Seven questions are a smoke test, not a benchmark, and similarity scores can't be compared across models. Next step: an answer key and recall@k for every embedder.

Sales forecasting with a neural network

A scikit-learn neural network that forecasts monthly sales for ten items from 2019 to 2024 order history. The data is a company's and stays private; the code and the error figures are public.

What I built. I cleaned 49,272 order lines (117 partial-month, zero-quantity and duplicate rows removed), built lag, rolling-average and seasonal features, and trained five versions of the model. The final one pools all ten items, works on log-scaled values and averages ten random seeds. I tested it on the last 12 months, which it never saw, against four baselines, and dropped one variant (a bias correction) because it made the error worse.

What I found. The final model's error is about 12% lower than the best baseline (78.7% against 89.6% for repeating the same month last year), and about 27% lower once the bulk order is set aside (66.7% against 91.9%). Against the best baseline, it has the lower error on six of the ten items over the full year, and on eight of ten without the bulk-order month.

Relevant to: time-series features, model evaluation against baselines, honest reporting.

  • Source code
Limit. It under-forecasts total volume by 37%, or about 1.5% without the bulk-order month. There is one hold-out period and only ten items, so read the model ranking as a hint, not a verdict.

CyberAI: threat triage for links, emails and PDFs

CyberAI checks whether a link, email or PDF looks safe and returns Clean, Suspicious or Malware, with the reasons. It runs from the command line or a small Flask web page, keeps a SQLite history and exports PDF reports.

What I built. One score from many signals: VirusTotal reports, DNS records, domain registration data, spam blocklists, SPF, DMARC and DKIM checks, look-alike domains and phishing wording. Each finding adds points, and the verdict lists the findings behind the total.

What it shows. How to turn messy signals from different services into one decision, and keep that decision explainable.

Relevant to: feature design from mixed data sources, API integration, serving results.

  • Source code
Limit. The point values are set by hand, not learned from data, so I can't report precision or recall yet. Next step: train a classifier on public phishing data and compare it with this score.

Gapminder dashboard: 55 years of life expectancy and income

An animated Quarto report, built with R and Plotly for a data-visualization course, on how life expectancy and income changed in 142 countries between 1952 and 2007.

What I found. Population-weighted life expectancy rose on every continent. Asia gained the most, from 42.9 to 69.4 years, and the gap between the highest and lowest continent narrowed from 30.4 to 26.5 years.

What I chose. The continent chart weights each country by its population, because a plain average would count a small country the same as China or India.

Relevant to: exploratory analysis, picking the right aggregate, explaining results to non-specialists.

  • Source code
Limit. The data stops in 2007 and is sampled every five years.

Fixed-width data extractor

A Python script that turns fixed-width text reports into clean Excel tables. It finds the columns from the header, rebuilds rows that wrap across several lines, and formats the sheet.

What it shows. Data preparation, the unglamorous first step of most ML work. I built it with a classmate for a graduate course, and our outputs matched.

Relevant to: data cleaning and preparation.
