Neural Networks: From Scratch to CNNs

Four graduate assignments that build one idea up. I wrote the forward and backward pass by hand in NumPy, then ran ten one-change experiments on California housing prices and ten convolutional-network variations on CIFAR-10. Every chart on this page is drawn from the recorded numbers, and each section says what they do not show.

Relevant to: neural networks, backpropagation, gradient descent, regression, mean absolute percentage error (MAPE), early stopping, dropout, batch normalization, convolutional neural networks (CNN), image classification, data augmentation, overfitting, hyperparameter experiments, NumPy, Keras, TensorFlow.

Assignments 1 and 2: a network built by hand

Assignment 1 is a forward pass in NumPy: a dense layer, a sigmoid and a mean-squared-error loss, chained into a 3-4-4-1 network (three inputs, two hidden layers of four sigmoid neurons, one output). Assignment 2 adds a backward pass for each piece and a 500-epoch gradient-descent loop with a learning rate of 0.05. The network has 41 trainable parameters and trains on 100 synthetic samples.

Assignment 3: ten Keras experiments on housing prices

A dense network predicts California house prices from eight census features. The score is mean absolute percentage error (MAPE): how far off each prediction is, in percent, averaged over the houses. Lower is better. Each experiment changes one thing in the best configuration so far and is kept only if validation MAPE improves. The test set only reports each model's final score.

Step through the ten experiments

KeptReverted

  1. 1. Base model Baseline

    Starting point. two hidden layers (64, 32), ReLU, Adam 0.001, 50 epochs, price divided by 100,000.

    What happened. Test MAPE 21.33%, test MAE $38,873, R2 0.752. 2,689 parameters.

    Hidden layers 64-32, MSE loss, batch size 32, 50 epochs run. Validation MAPE 21.22%, test MAPE 21.33%, test MAE $38,873.

  2. 2. Wider and deeper network Kept

    Changed. Added a third hidden layer and doubled the first: 128-64-32.

    Why I expected it to help. House prices depend on non-linear interactions such as latitude with longitude (coast against inland), and more capacity can learn them.

    What happened. Validation MAPE fell from 21.22% to 19.16%. Kept.

    Hidden layers 128-64-32, MSE loss, batch size 32, 50 epochs run. Validation MAPE 19.16%, test MAPE 19.25%, test MAE $38,439.

  3. 3. Mean absolute error loss Reverted

    Changed. Loss function: mean squared error to mean absolute error.

    Why I expected it to help. MSE squares errors, so a few very expensive homes (prices are capped at $500,001) dominate training. MAE is closer to how MAPE scores a model.

    What happened. Both metrics got worse (test MAE $41,142). MAE gives every error a same-sized gradient, so within 50 epochs it had not caught up. Reverted.

    Hidden layers 128-64-32, MAE loss, batch size 32, 50 epochs run. Validation MAPE 19.80%, test MAPE 19.48%, test MAE $41,142.

  4. 4. Log-transformed target Reverted

    Changed. Trained on ln(price) instead of price / 100,000, then converted back with exp() before scoring.

    Why I expected it to help. MAPE is a relative error. On a log scale a 10% miss is the same size for a $60,000 home and a $450,000 one.

    What happened. The biggest surprise: MAPE got worse (22.00%). Small log-scale errors are magnified by exp(), and it was tested before early stopping was added, so it may not have converged. Reverted.

    Hidden layers 128-64-32, MSE loss, batch size 32, 50 epochs run. Validation MAPE 22.28%, test MAPE 22.00%, test MAE $39,821.

  5. 5. More epochs with early stopping Kept

    Changed. Up to 200 epochs with early stopping (watch val_loss, patience 15, restore the best weights).

    Why I expected it to help. 50 epochs may stop before convergence. Early stopping trains longer, then stops and keeps the best weights, which guards against overfitting.

    What happened. Validation MAPE 18.94%, the lowest of all ten. It stopped at epoch 133. Test MAE $34,949, R2 0.784. 11,521 parameters. Kept.

    Hidden layers 128-64-32, MSE loss, batch size 32, 133 epochs run. Validation MAPE 18.94%, test MAPE 18.91%, test MAE $34,949.

  6. 6. Learning-rate reduction on plateau Reverted

    Changed. Added ReduceLROnPlateau: halve the learning rate after 5 epochs without improvement (minimum 1e-6).

    Why I expected it to help. A fixed learning rate can bounce around the minimum late in training. Smaller steps let the optimizer settle.

    What happened. Lowest dollar error of all (test MAE $34,670) but MAPE was worse (19.57%): the extra training mainly cut errors on expensive homes while percentage errors on cheaper homes grew. Reverted.

    Hidden layers 128-64-32, MSE loss, batch size 32, 200 epochs run. Validation MAPE 19.41%, test MAPE 19.57%, test MAE $34,670.

  7. 7. Larger batch size Reverted

    Changed. Batch size 32 to 64.

    Why I expected it to help. Smoother gradients and faster epochs, unless the noise of small batches was helping the model generalize.

    What happened. Worse (test MAPE 20.04%). Half as many updates per epoch and less gradient noise; the noise at batch size 32 may have helped. Reverted.

    Hidden layers 128-64-32, MSE loss, batch size 64, 95 epochs run. Validation MAPE 19.64%, test MAPE 20.04%, test MAE $36,498.

  8. 8. Dropout regularization Reverted

    Changed. Dropout (rate 0.1) after each hidden layer.

    Why I expected it to help. Switching off 10% of neurons at random usually reduces overfitting, which matters more in a bigger network.

    What happened. Worse (20.04% against 18.91%). Dropout is meant to reduce overfitting, and the validation and test MAPE of this model were already close (18.94% and 18.91%). Reverted.

    Hidden layers 128-64-32, MSE loss, batch size 32, 102 epochs run. Validation MAPE 19.73%, test MAPE 20.04%, test MAE $35,887.

  9. 9. Batch normalization Reverted

    Changed. BatchNormalization between each dense layer and its activation.

    Why I expected it to help. Stable layer inputs often speed up convergence and make deeper networks easier to train.

    What happened. Worse (20.39%). Validation loss became noisier from epoch to epoch and the 15-epoch patience ran out at epoch 42, before the model reached its best. Reverted.

    Hidden layers 128-64-32, MSE loss, batch size 32, 42 epochs run. Validation MAPE 20.27%, test MAPE 20.39%, test MAE $37,167.

  10. 10. Swish activation Reverted

    Changed. Hidden-layer activation: ReLU to Swish, x * sigmoid(x).

    Why I expected it to help. ReLU outputs exactly zero for negative inputs, so some neurons can stop learning. Swish is smooth and passes small negative values.

    What happened. Close (19.61%) but not better. With inputs scaled to [0, 1] and a network this small, dying ReLU was not a real problem. Reverted.

    Hidden layers 128-64-32, MSE loss, batch size 32, 196 epochs run. Validation MAPE 19.53%, test MAPE 19.61%, test MAE $35,549.

Test MAPE fell from 21.33% (base model) to 18.91% (Model 5), with test MAE $34,949 and R2 0.784. Only two of the nine changes were kept: more capacity (Model 2) and longer training with early stopping (Model 5).

Assignment 4: ten CNN variations on CIFAR-10

A small convolutional network classifies 32 by 32 color images into ten classes (CIFAR-10: 50,000 training and 10,000 test images). The base model has two convolutional layers (32 and 64 filters), 2 by 2 max pooling and a 64-neuron dense layer. Each variation changes one thing: depth, width, dropout, batch normalization, optimizer, learning rate, augmentation, epochs or activation.

Test accuracy by variation

  1. 1. Base model Base model

    Changed. Baseline: two conv layers (32, 64 filters) with max pooling, one 64-neuron dense layer, ReLU, no regularization.

    Reading. The reference point for every other row.

    Conv 32-64, Dense 64. Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 71.65%, training accuracy not reported.

  2. 2. Deeper network +2.89 points

    Changed. A third conv layer (128 filters) to see whether more depth builds richer features (edges, then textures, then object parts).

    Reading. Best of the ten, +2.89 points. The only change that clearly helped.

    Conv 32-64-128, Dense 64. Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 74.54%, training accuracy not reported.

  3. 3. Dropout regularization -3.62 points

    Changed. Dropout(0.5) after the dense layer so no single neuron can be relied on.

    Reading. 3.62 points below the base model. Training accuracy (60.12%) sits below test accuracy because dropout is only active while training.

    Conv 32-64, Dense 64 + Dropout 0.5. Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 68.03%, training accuracy 60.12%.

  4. 4. Batch normalization -3.42 points

    Changed. BatchNormalization after each conv layer to stabilize and speed up training.

    Reading. A 20-point gap between training (88.6%) and test (68.23%): the overfitting pattern.

    Conv 32-64 (+BN), Dense 64. Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 68.23%, training accuracy 88.60%.

  5. 5. SGD with momentum -3.33 points

    Changed. SGD with momentum 0.9 and learning rate 0.01 in place of Adam.

    Reading. 3.33 points below Adam at the same 10 epochs.

    Conv 32-64, Dense 64. SGD, momentum 0.9, learning rate 0.01, batch size 64, 10 epochs. Test accuracy 68.32%, training accuracy not reported.

  6. 6. Lower learning rate -11.69 points

    Changed. Adam with the learning rate cut from 0.001 to 0.0001.

    Reading. The weakest result, 11.69 points below the base model. The report reads it as a rate too cautious to converge in 10 epochs.

    Conv 32-64, Dense 64. Adam, learning rate 0.0001, batch size 64, 10 epochs. Test accuracy 59.96%, training accuracy not reported.

  7. 7. Wider network +0.10 points

    Changed. Every conv filter count doubled (64, 128) to add capacity through width instead of depth.

    Reading. +0.10 points. With one run per variation, a gap this small should not be read as a real difference.

    Conv 64-128, Dense 64. Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 71.75%, training accuracy not reported.

  8. 8. Data augmentation -2.15 points

    Changed. Random flips, rotations and shifts of the training images each epoch.

    Reading. Training accuracy (66.61%) sits below test accuracy (69.50%) because training images are distorted while test images are clean.

    Conv 32-64, Dense 64. Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 69.50%, training accuracy 66.61%.

  9. 9. More epochs -1.78 points

    Changed. The base architecture trained for 20 epochs instead of 10.

    Reading. Highest reported training accuracy (92.87%) with below-average test accuracy: overfitting.

    Conv 32-64, Dense 64. Adam, learning rate 0.001, batch size 64, 20 epochs. Test accuracy 69.87%, training accuracy 92.87%.

  10. 10. LeakyReLU activation -0.42 points

    Changed. LeakyReLU in place of ReLU in every conv and dense layer, to avoid neurons stuck at zero.

    Reading. -0.42 points. With one run per variation, a gap this small should not be read as a real difference.

    Conv 32-64, Dense 64 (LeakyReLU). Adam, learning rate 0.001, batch size 64, 10 epochs. Test accuracy 71.23%, training accuracy not reported.

  • Depth helped and little else did. The third convolutional layer added 2.89 points. Doubling the filters (+0.10) and LeakyReLU (-0.42) are too small to separate from run-to-run noise.
  • The training-test gap shows overfitting. More epochs reached 92.87% training accuracy against 69.87% on test, and batch normalization 88.6% against 68.23%.
  • A learning rate of 0.0001 was the weakest result (59.96%). Steps that small did not converge in 10 epochs.

Limit. One run per variation and no validation set, so the best of ten test scores is probably a little optimistic. Ten epochs favors setups that learn quickly: dropout, augmentation and a lower learning rate usually need longer runs, so these results describe a 10-epoch budget only.

What these numbers do and do not show

  • Single runs. Each Keras result is one training run. Differences of about a point or less, such as 71.65% against 71.75% in assignment 4, are not enough to rank two variations.
  • Selection. Assignment 3 keeps changes by validation MAPE, as intended, but the "best model" line at the end of its script picks the lowest test MAPE. Both rules choose Model 5 here. Assignment 4 has no validation set, so 74.54% is probably a little optimistic.
  • Source of the numbers. The Keras numbers are copied from the reports I submitted with those assignments, not re-run for this page. The script that ran the ten CNN variations is not in the repository; the best model's script is.
  • Scope. These are course exercises on standard datasets, not production models.
